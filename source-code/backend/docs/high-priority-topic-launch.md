# High-priority textbook-topic launch

This process releases one reviewed topic without requiring the rest of its Unit, Module or textbook to be ready.

1. In **Textbook structure**, open the correct iGCSE subject textbook. Create the Unit or Module and its child topic. Existing topic references and published content versions remain unchanged when later groups or topics are added.
2. Upload each textbook part to the child topic. In **Manage topic sources**, choose one canonical `primary` source. Use `supporting` or `reference` only for distinct reviewed text. Use `visual_reference` for scans retained for provenance or later diagram selection; their OCR text is excluded from normal retrieval.
3. In **Documents & textbooks**, clear every required page and block review. Saving the final item changes the version to `completed`, the Library state to `reviewed`, and active topic attachments to `ready`. This does not publish the topic.
4. Return to **Textbook structure** and inspect publication readiness, the PDF quality report, duplicate warnings and the source preview. Publish only when the intended source manifest is correct.
5. In **Grade & term coverage**, add the independently published topic at the Grade and Term where teaching begins. Publish the coverage version. Later terms receive it through cumulative progression.
6. Choose a pilot Student beside **View launch readiness**. Resolve each failed item using its **Fix this step** link. Student eligibility requires an active account, iGCSE progression, subject enrolment, published cumulative coverage and published topic content.
7. Keep Student access disabled until canonical retrieval, Tutor and flashcard evaluation gates pass. The readiness panel deliberately stays blocked while deck generation, deck release or Student release is incomplete.

For the next Chemistry topic, repeat these steps with a new child topic. Do not rename, replace or reuse the States of Matter topic reference, published content version or retrieval chunks.

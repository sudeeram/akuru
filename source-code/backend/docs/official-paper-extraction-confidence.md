# Official-paper extraction confidence

New draft-bank imports store an immutable, versioned extraction-confidence estimate on each question and subpart. Admin review lists can sort the lowest estimates first and show the reasons. The estimate is **not** a measured probability that wording, marks, diagrams or examiner advice are correct; it is a triage signal for deciding what to inspect first.

`paper-extraction-triage-v1` uses the weakest uploaded question-paper and marking-scheme page extraction confidence, checks whether draft question and scheme text exist, and flags unusually short wording, page furniture and dotted answer spaces. Candidate examiner-report pages affect the estimate when their extraction confidence is low, but a missing candidate report page is not treated as an extraction failure: a report may legitimately have no comment on that question. Imported page-level evidence cannot establish exact subpart links, marks, visual completeness, handwritten report meaning or scientific correctness, so the estimate is capped at 70%. Any such issues still require Admin comparison with the original PDFs.

The stored estimate and reasons remain unchanged when an Admin edits or approves the review. This preserves the original import-quality signal and stops a client from replacing it with an arbitrary score. Manually created and older questions have no estimate and appear after scored questions in the low-confidence sort. Confidence never bypasses question, subpart, visual, source or release gates. A later, separately versioned method can incorporate exact reviewed blocks and calibrated evaluation data without rewriting historical estimates.

# Tutor Step 6 — Structured Tutor conversation

The Tutor room sends text through the structured `agent-turns` endpoint. Students can choose Explanation, Questions, Guided practice, Socratic practice, Revision, Exam technique or French conversation. Pressing Enter submits the form; failures leave the typed message available for correction or retry.

The conversation refreshes after a successful response. The current structured reply displays authorized textbook citations, approved visual material and selectable follow-up choices. Source and media links remain authenticated. The interface states that tutor observations cannot change mastery or the study plan.

If approved evidence is insufficient, AKURU displays the backend's cautious response. The browser does not construct citations, infer learner claims or call OpenAI directly.

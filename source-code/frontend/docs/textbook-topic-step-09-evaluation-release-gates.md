# Step 9 — Admin quality and release gates

In **Textbook structure**, each topic has **View topic PDF quality report**. The report shows whether every attached PDF passes page coverage, OCR, equation, diagram, printed-page and topic-retrieval checks. A blocked report explains that the Admin should review flagged extracted pages or blocks in **Documents & textbooks**; saved corrections are audit logged.

The existing **Evaluation gates** section manages reviewed assessment and Tutor corpora, regression runs, staged release audiences, and a kill switch. Automatic student features remain unavailable until their approved corpus and passing run meet every threshold.

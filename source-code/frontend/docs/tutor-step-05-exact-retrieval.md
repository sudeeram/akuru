# Tutor Step 5 — Exact textbook sources

The Student Tutor room has an **Approved textbook** panel for the active unit. The Student enters a question and receives only citations authorized by the backend for that session, unit and published edition.

Each result displays the content type, textbook title, edition, immutable document version, confidence, exact passage and a page reference that distinguishes the printed label from the physical PDF page. **Open cited page or crop** uses the authenticated private asset route. **Show nearby context** retrieves approved passages from the same unit and version for a fuller explanation.

The interface displays the backend's evidence-insufficient message when no exact result exists. It does not construct page references or infer editions in the browser. Tutor profile and unit switches clear prior source results so stale citations are not presented as current evidence.

# Step 5 — Topic coverage editor

The Admin coverage page groups published topics under their configured Unit or Module. Each Grade and Term shows topics introduced in that period and a cumulative preview through that point.

After publishing, **Add topics covered now** creates a new draft copied from the published plan. The editor distinguishes published selections from draft changes and lists added, moved and removed topics. Moving or removing published coverage displays an impact warning and requires explicit confirmation when publishing. Existing assessments retain their saved curriculum snapshot.

The page displays the public plan version, source version, status and publication information without exposing internal database identifiers.

# Step 6 — Topic mapping review

The Admin Question mapping page now displays candidates under their Unit or Module. For each published question, the Admin sees the extracted prompt, shared evidence and source pages before reviewing mappings.

Multiple topics can be selected across groups. Each selection has a percentage weight and a **Required** control. Weights must total 100 percent and at least one topic must be required. A group summary helps reviewers check how the question spans the wider textbook structure.

The page shows confirmed-question progress for the full paper. Confirmation makes that question version's mapping immutable. Cross-subject and unpublished topics are rejected by the backend even if a client attempts to submit them.

# Textbook topics Step 2: Admin structure editor

The Admin **Textbook structure** screen manages the catalogue before any scanned PDF is uploaded.

An Admin can create a textbook with subject, title, edition, publisher and a Unit or Module label; add and edit its groups and topics; move entries earlier or later; remove eligible draft entries; and publish the complete structure. Catalogue entries show subject, edition, state, group count, topic count and structure version. Topic rows also show whether textbook parts have been attached.

The screen uses only public references. Published or referenced entries disable removal and explain why they are protected. API validation messages are shown directly for duplicate codes, duplicate order, incomplete structures and protected content. Publishing requires a browser confirmation and creates an immutable backend version.

# Tutor Step 4 — Next-unit guidance

The Student Tutor room includes **What should I improve next?**. Selecting **Find next unit** requests the deterministic backend ranking and displays the recommended unit, evidence-based reason and suitable activity.

The recommendation is advisory. It never changes the active unit automatically. **Move to this unit** is a separate Student action and uses the authenticated Step 2 unit-switch operation. The interface also displays clear no-evidence and no-eligible-unit messages returned by the backend.

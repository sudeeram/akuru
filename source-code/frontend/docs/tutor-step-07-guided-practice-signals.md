# Tutor Step 7 — Guided practice and Tutor observations

The Student Tutor room can start one eligible question for its current covered unit. The panel shows the official prompt, equations and authorized question diagrams. Students can request successive recorded hints, save an answer and submit it to the AKURU assessment service. Tutor switching retains the question. The active question must be submitted before changing units.

Published assessment feedback displays the awarded marks, decision rationale, evidence from the Student answer, small improvements, improved answer and teaching explanation. When a result requires review, the panel states that feedback is awaiting the permitted workflow and does not expose draft details.

Tutor observations appear for the Student and in each linked Parent's child summary. Every card is labelled **Non-authoritative** and shows its confidence and evidence count. The interface explains that observations do not change mastery or study plans.

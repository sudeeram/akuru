# Tutor Step 11 — Visual learning aids

The tutor room displays visual aids only in response to a visual request. Blue `OFFICIAL SOURCE` cards identify approved textbook evidence. Teal `EXPLANATORY AID` cards identify reviewed or deterministic supporting media and state that they do not replace the source.

Images use meaningful alt text, repeat the text alternative visibly, and provide a keyboard-operated **Enlarge diagram** dialog with a scrollable viewport. The original private asset can be opened at full size. Equations use native MathML where supported and always retain the readable source notation if rendering is unavailable.

An expandable provenance section lets a learner or reviewer inspect the asset’s source and review chain without exposing internal database identifiers in the normal learning flow.

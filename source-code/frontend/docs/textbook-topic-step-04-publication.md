# Textbook topics Step 4: publication workflow

The Admin **Textbook structure** screen now shows each topic as no document, processing, needs review, ready, published or failed. A topic displays extraction confidence, its current content version and a checklist explaining anything that blocks publication.

The textbook header reports published topics out of total topics. This counts only independently published content and does not present uploaded or reviewed drafts as student-ready material.

When every check passes, Admin can use **Publish topic content** and confirm the action. Topics publish independently, so Chemistry Topics 1 and 2 can be available while Topics 3–29 remain absent or under review. Correcting and republishing one topic creates a new content version while preserving prior source and citation history.

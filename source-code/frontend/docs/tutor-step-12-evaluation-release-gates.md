# Tutor Step 12 — Admin evaluation and release controls

The Admin **Evaluation gates** page now separates assessment and Tutor corpora. The Tutor template lists the complete quality, safety, voice and operational review evidence. Admins select the subject, modality and CI or production-like staging environment, submit observed results, and see every threshold and failure.

Passing Tutor runs expose controls for text, voice, the Tutor tool bundle and each sensitive tool. Releases must move through **Admin testing**, **Parent pilot**, and **Eligible students**. Only staging runs can reach students. **Disable feature** applies the audited database kill switch immediately.

The dashboard identifies each iGCSE subject without an approved Tutor corpus. Full identifiers and evaluation evidence remain available only on this Admin page.

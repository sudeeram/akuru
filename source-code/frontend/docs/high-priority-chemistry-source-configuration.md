# Admin Chemistry Topic configuration

Open **Textbook structure**, find the Chemistry textbook and expand **Manage topic sources** for Topic 1.

The Admin can:

1. Apply the recommended v2.1 source roles after reviewing the confirmation.
2. Verify the clean v2.1 PDF is labelled **Primary text**.
3. Verify the original scan is labelled **Visual reference** and **OCR text excluded from retrieval**.
4. Use the authoritative checklist to open remaining Library review work.
5. Open **Select and review visual assets** on a visual reference.
6. Inspect each diagram, image, or table with its exact page.
7. Add or correct its caption and accessible text alternative.
8. Exclude it, save it for later review, or approve it for the next Topic version.
9. Review the complete source and asset preview before publishing Topic content.

Only approved visuals enter the next Topic version. The Student never sees unreviewed selections, and visual-reference OCR does not become Tutor or flashcard evidence.

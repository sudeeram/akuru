# Step 7 — Topic-aware learning screens

Student progress now presents each Unit or Module as an expandable summary with its topic mastery results beneath it. Topic scores show only published assessment evidence and retain the evidence confidence returned by the API.

The Tutor room selects a covered topic when a subject uses the new topic hierarchy. It shows the parent group in the selector, supports covered-topic switching, and labels exact textbook citations with their reviewed page details. Legacy unit sessions remain visible for existing records.

Parent summaries show group-level progress and identify topic weaknesses that need focused practice. Study-plan and recommendation responses carry topic and parent-group labels when a topic-scoped learning record is returned.

# Try the Chemistry teaching pilot

The initial pilot is available to the selected Student account only, for Chemistry Topic 1 — States of Matter. Other published topics, voice and assessed guided-practice questions are not part of this trial.

1. Sign in with the selected Student's usual credentials.
2. Open **Tutors** (`/student/tutors`). Create a tutor using the available safe avatar/personality choices, or use the tutor already prepared for the pilot.
3. Open **Tutor room** (`/student/tutor-room`). Select Chemistry, States of Matter and your tutor, then start a session.
4. Ask a question by text. Try “Why does a solid keep its shape but a liquid flow?” and a short follow-up such as “So are particles in a solid still?”
5. Ask “Explain Figure 1.4” to check an approved textbook figure. Open the cited source to compare the answer with the reviewed textbook.
6. Try revision mode for short revision questions. End the session when finished; its transcript remains available and the parent can see a session summary.

Answers are AI generated and can need correction. AKURU should explain missing source evidence rather than invent textbook claims or personal performance history. Tutor help is blocked during formal assessments. The Admin can disable the pilot; it also has a configured expiry.

Production conversations use the AKURU-backend OpenAI project and the existing per-student allowance. The separate Evaluation budget does not cap production usage. No password change is needed to enable the pilot.

## Conversation controls

The Tutor room shows Student and AI messages as separate chat bubbles with timestamps. While a request is being sent, the question appears immediately with a reply-preparation indicator; the page brings the new answer into view when it arrives.

**Textbook references** starts collapsed to keep the conversation readable. Select it to show the cited pages and available visual aids, and select it again to hide them. Follow-up suggestions remain outside this section. A new answer starts with its references collapsed. When an answer has no source evidence, no empty reference section is shown.

Tutor avatars load directly from AKURU's saved assets. If a selected image is unavailable, a default AKURU BOT is displayed. The source links and tutoring permissions are unchanged by this presentation.

## Additional explanations (controlled rollout)

When enabled for your pilot account, the Tutor can explain closely related concepts even when a published passage does not cover every detail. **Textbook-supported explanation** uses the actual textbook references. **Additional explanation** is clearly labelled and extends beyond those retrieved passages; it is not an official Pearson answer. A reply can contain both sections.

Ask a direct question such as “What is evaporation?”, then a follow-up such as “Why does it happen?”. If the question is unclear or outside the selected learning scope, AKURU may ask for clarification. References remain collapsed until you open them. Additional explanations do not change your marks, mastery or study plan.

This rollout is awaiting live evaluation and production activation; the existing pilot restrictions still apply.

# Importing a textbook prepared from screenshots

The import workflow was deployed on 2026-11-01. Importing still creates a separate draft: the prepared Topic 1 candidate has not been imported into production or substituted for its current published source.

1. An operator prepares the screenshot-derived reading document, figures, tables, exercises and exception list, then creates a validated AKURU ZIP package. A Word document or newly typeset primary PDF is not required.
2. Sign in as Admin. Open **Textbooks → View textbooks → Manage**, then the destination topic. Expand **Import prepared screenshot textbook**.
3. Select the prepared ZIP and choose **Validate and preview package**. Check the destination and counts. Choose **Import supporting draft**. The currently published textbook is preserved.
4. Choose **Review prepared draft**, then **Open editable document and source pages**. Read the full assembled content and compare source pages, tables, exercise wording and scientific notation. Save wording corrections in the existing review editor.
5. Return to the topic and reopen **Review prepared draft** to load the current content hash. Enter a reviewed clarification/decision for every exception. These notes become visible teaching evidence, not private Admin comments. Confirm the whole-document checkbox and choose **Confirm whole-document review**. This is an explicit Admin review of the complete package, not just its exception list.
6. Under **Manage topic sources**, separately approve or reject the selected figures and their captions/accessibility descriptions. Text review does not approve figures automatically.
7. When ready to replace a source, set the prepared draft to **Primary text** and change the earlier primary to its appropriate non-primary role. Retain the original **Visual reference**, with its reviewed printed-page labels. Do not change primary roles merely to try the import.
8. Check the topic quality/readiness report, publish the reviewed topic through the normal workflow and run retrieval preflight. Test student textbook/flashcard evidence before changing released learning material.

If the draft changed after the form was loaded, reload it and review again before confirmation. Published evidence is read-only; use a review revision for later edits. Importing a ZIP does not generate or replace flashcard decks.

Record the time needed to review the prepared content so we can compare this process with manual textbook preparation. Do not include upload or navigation time in the content-review measurement.

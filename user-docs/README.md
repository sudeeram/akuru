- [Data and safety](DATA-AND-SAFETY.md): private data, local accounts and current limitations.

Phase 1 supports iGCSE, Grade 10 and Grade 11, with Term1, Term2 and Term3.
Students retain multiple completed/current Grade + Term combinations. A Grade 10
Term2 student uses both Grade 10 Term1 and Grade 10 Term2 coverage.
Subjects: English, Maths, ICT, Biology, Chemistry, Physics, French, Human Biology.

Only Admin manages accounts, enrolments and learning documents. This supersedes
the earlier guides that assigned course setup and uploads to parents.

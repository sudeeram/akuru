# Reviewing official exam papers

The official-paper workspace is available to Admin users under **Exam Documents → Past papers → Review questions**. It is an internal draft workspace. Saving or approving a question does not make it available to Students.

1. Upload the original question paper as a **Past paper**, with the correct course, subject, examination year, session, component and variant. Upload its exact **Marking scheme**, selecting that paper as the related source. An **Examiner report** is optional and can be attached later. Wait for extraction to finish.
2. Open **Review questions** on the past-paper row. Select the matching scheme and optional report, enter the complete number of top-level questions, and start the workspace. Each workspace is bound to the uploaded source versions; if a source PDF changes, ask a developer to handle the version change before continuing.
3. Open a question or add one. Check the source page alongside the extracted blocks. Correct the full question wording, shared stem, subpart wording and marks. **Link this block** to record exact evidence for the question and each subpart. Do the same for the marking-scheme block. Page-only links can be saved in drafts but do not satisfy approval.
4. For each subpart, review the marking points and accepted alternatives. Enter marking points as `code|kind|text|optional dependency`, one per line. The allowed kinds are `method`, `accuracy`, `independent`, `communication` and `other`. Add examiner guidance only when supported by the attached report.
5. Select a coverage decision: **supported**, **partial or uncertain**, or **outside current coverage**. For supported parts, link one or more published topics in the same subject and explain the match. A wording similarity or draft suggestion is not a confirmed mapping. A whole question with any unsupported required part is not eligible for a term mock.
6. Save after each correction. Set subparts to **approved** only after their wording, marks, scheme evidence and coverage decision are checked; then approve the question. Reopening an approved question resets its subpart approvals. The progress summary shows remaining blockers. An excluded question needs a reason and still counts in the source inventory.
7. When every question in the complete inventory is approved, **Prepare official paper and scheme drafts**. Review those drafts in Exam Documents. Publish the paper and then its exact marking scheme using the existing confirmation controls. A partially reviewed paper remains unavailable to Students.

For the June 2025 Chemistry pilot, an Admin may import the unreleased draft-bank JSON after uploading the exact matching PDFs. The import checks the PDF hashes and page inventory and seeds **unapproved proposals**. It never publishes material. The private draft-bank, triage JSON, licensed PDFs and rendered pages must stay outside Git.

# Textbook administration parity checklist

The routed Textbooks workspace preserves the earlier combined-page capabilities while separating assessment material into Exam Documents.

| Earlier capability | Current location |
| --- | --- |
| Create a textbook | Textbooks → Add Textbook |
| Find and select a textbook | Textbooks → View Textbooks |
| Edit/archive/publish a textbook | Textbooks → Manage |
| Add, edit, order, or safely remove Units/Modules and Topics | Textbooks → Manage |
| Upload one or more Topic files | Textbooks → Manage → Topic upload panel |
| Inspect quality, source roles, visuals, retrieval, readiness, and publication | Textbooks → Manage → Topic |
| Review extracted textbook pages and blocks | Textbooks → Review Textbooks |
| Upload/review past papers, marking schemes, examiner reports, and references | Exam Documents |
| Retry or remove failed documents | The relevant review table |

The UI change does not delete database records, stored files, published versions, citations, or audit history. Legacy `/admin/library` links redirect to `/admin/exam-documents`; unknown public references show the existing safe unavailable state.

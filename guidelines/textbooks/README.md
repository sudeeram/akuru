# Textbook preparation guidelines

Use [the iGCSE screenshot standard](igcse/README.md) for screenshot, photograph and scanned-page preparation. Its first evaluated profile is Pearson Edexcel iGCSE Chemistry. Other qualifications need their own checked profile rather than inheriting exam scope or difficulty assumptions.

Textbook preparation creates source-linked learning evidence; it does not create official marking schemes, calibrate exam difficulty or approve publication. Licensed originals and derived content stay outside Git under the ignored `textbooks/` directory. This folder holds reusable rules, synthetic contracts, blank checklists and sanitised review records.

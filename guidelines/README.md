# AKURU guidelines

Standards for preparing, interpreting and reviewing source materials before they enter AKURU. Organise each document family in its own folder; keep implementation details in `developer-docs` and delivery work in `source-code/todo`.

- [Past papers](pastpapers/README.md)

## How to apply a guideline

1. Select the document family, qualification and applicable awarding-body profile.
2. Read its index and all applicable analysis and validation rules.
3. Record the exact guideline version alongside source identity and processing provenance.
4. Keep uncertain results as proposals with evidence and review issues.
5. Use AKURU's authorised import/review workflow; a guideline does not grant publication approval or permission to bypass authentication.

Guidelines describe required outcomes. A documented rule is not proof that software enforces it. Each family must identify implementation gaps and link its delivery plan. Existing product security, family isolation and release rules continue to apply.
